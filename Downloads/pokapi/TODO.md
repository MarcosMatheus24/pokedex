# Entregas

- [x] Tela de entrada animada com fundo amarelo Pikachu, arte do personagem em destaque, título grande “POKÉDEX” e transição suave para a aplicação.
- [x] Busca direta de Pokémon por nome ou número, com tratamento de resultados inexistentes.
- [x] Exploração do catálogo por lista paginada ou carregamento progressivo.
- [x] Filtros por tipo de Pokémon para refinar a listagem.
- [x] Cards de Pokémon com sprite, número, nome e tipos, usando cores e indicadores visuais coerentes.
- [x] Painel/modal de detalhes com imagem, tipos, altura, peso, habilidades, estatísticas base e descrição em português quando disponível.
- [x] Exibição da linha evolutiva quando disponível, além de navegação para o Pokémon anterior ou seguinte dentro do detalhe.
- [x] Sistema de favoritos com persistência local no navegador e visualização clara do estado favoritado.
- [x] Estados de carregamento e mensagens de erro amigáveis para consultas e falhas da API.
- [x] Interface responsiva e acessível, com navegação por teclado, foco visível, microinterações e uma seção de instruções/atividade para incentivar a exploração da Pokédex.
- [x] Seleção de até dois Pokémon diretamente nos cards para criar uma comparação lado a lado.
- [x] Comparação visual de estatísticas base, total de atributos e remoção individual da seleção.
- [x] Batalha simulada entre os dois selecionados, com cálculo de pontuação, vencedor e margem da disputa.
- [x] Tema cromático dinâmico aplicado à experiência enquanto houver seleção; ao remover a seleção, o amarelo Pikachu retorna.
- [x] Batalha animada em seis turnos com avanço visual dos Pokémon, ataques nomeados por tipo, barras de HP, log de combate e tela de vencedor.
